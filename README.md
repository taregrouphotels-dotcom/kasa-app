# Kasa — telefon kabuğu

Kasa web uygulamasını (Google Apps Script) telefonda kendi simgesiyle, tam ekran açmak için küçük PWA kabuğu.
Kod ve veri burada değil; bu repo sadece simge, manifest ve web app bağlantısını içerir.

Yükleme: GitHub Pages adresini telefonda açın → Android: ⋮ → **Uygulamayı yükle / Ana ekrana ekle** · iPhone (Safari): Paylaş → **Ana Ekrana Ekle**.
